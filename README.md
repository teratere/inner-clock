# ⏱️ Inner Clock Challenge - 体内時計ジャスト止め

音・数字・テンポガイド一切なし。完全な静寂の中で己の体内時計の感覚だけを頼りに、目標秒数ピッタリでタップして止めるミニマル体感ゲームです。

> **🌐 Live Demo:**  
> ブラウザですぐに遊べる公開版はこちら 👉 **[https://selfup.net/innerclock/](https://selfup.net/innerclock/)**

---

## 🌟 主な機能 (Features)

- **完全静寂・ブラインド測定:** 計測中は経過時間表示・音・点滅などのテンポ手がかりを完全排除。純粋な体内感覚のみを試せます。
- **マルチモード対応:**
  - `1.00秒 チャレンジ`（瞬間的な体内テンポ）
  - `10.00秒 ジャスト`（精神集中と持続感覚）
  - `カスタム秒数`（0.50秒〜60.00秒まで0.01秒単位で自由設定、クイックプリセット付き）
- **ミリ秒精度判定 & 6段階の称号バッジ:**
  - `±0.030秒未満`: 👑 神域・人間時計
  - `±0.100秒未満`: ⭐ 超感覚マスター
  - `±0.250秒未満`: 🎖️ 時間感覚の達人
  - `±0.500秒未満`: ⏱️ 標準的な地球人
  - `±1.000秒未満`: 🌀 ややズレ気味
  - `それ以降`: 🚀 時空の旅人
- **自己ベスト記録 (localStorage):** 各モードの最小誤差記録をブラウザ内に自動保存。
- **結果共有 & 高画質スクショ保存:**
  - 「📋 結果をコピー」で結果テキストをワンクリックでクリップボードへコピー。
  - 「📸 画像保存」でリザルトカードを高解像度PNG画像として直接ダウンロード。
